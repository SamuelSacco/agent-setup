## Claim under test

The installed `ux-ui` specialist agent closes a browser-verification
loop (inspect rendered state → edit → re-check) on a defective
static page where the base tool does not.

## Fixture

`evals/fixtures/x4-ux-ui/index.html` — one static page (inline
CSS/JS), committed with this prereg. Three planted defects, each
mechanically assertable without human eyes:

1. **Broken click handler.** `#add-btn`'s handler writes to
   `document.getElementById('cout')` (no such id; the counter
   element is `#count`), so clicking never updates the count.
2. **Low contrast.** `#status` text is `#b5b5b5` on a `#ffffff`
   background — measured 2.05:1 by the evaluator, below WCAG AA
   4.5:1.
3. **Missing accessible label.** `#add-btn` is an icon-only button
   (fullwidth-plus glyph) with no `aria-label`.

## Independent assertion method

`evals/fixtures/x4-ux-ui/assert.mjs` — evaluator-owned, never part
of an arm's tree. It launches the system Chromium
(`/opt/meta-chromium/chrome`, `--no-sandbox`) via playwright-core,
opens the page over `file://`, and checks:

- two clicks on `#add-btn` leave `#count` text exactly `2`;
- computed contrast ratio of `#status` vs its effective background
  is ≥ 4.5 (WCAG formula);
- `#add-btn` carries a non-empty `aria-label`.

Exit 0 iff all three pass; prints a JSON evidence object.

Pre-run oracle validation (both directions, recorded before arms):

- Pristine fixture: exit 1 — `click_updates_count: false`
  (countText `0`), `contrast_ratio: 2.0505`, `aria_label_present:
  false`. The assertion script FAILS on the pristine fixture.
- Hand-fixed scratch copy (all three defects repaired): exit 0 —
  countText `2`, contrast 7.0047, aria-label `Increment count`.

## Loop-closed definition

An arm CLOSES THE LOOP iff, with no human input: it inspects
rendered state via Playwright (screenshot and/or DOM), edits
files, re-checks, and the independent assertion script then passes
on its final tree. Inspection/edit/re-check are read from the arm's
stream-json transcript on disk; the pass is the evaluator's exit
code on the arm's final `index.html`, never the arm's self-report.

Per arm recorded: loop closed or not, `num_turns` and
`total_cost_usd` from the stream-json result event, wall seconds,
what the arm actually did (transcript), evaluator JSON output,
final-tree screenshot from the evaluator.

## Decision rule (pre-registered verbatim)

X4 PROVEN iff arm B closes the loop AND arm A does not. REFUTED
iff arm A also closes the loop with equal-or-fewer turns, or arm
B fails to close it. UNVERIFIABLE iff the Playwright loop cannot
run in either arm (record the exact failure) or an arm's
invocation path does not exist.

Gap note (added at registration): an outcome matching no clause
(e.g. both close, B in fewer turns) is reported as UNVERIFIABLE
with the gap named, not forced into a clause.
