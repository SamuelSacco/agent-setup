### Arm B (ux-ui agent) — what it did (transcript on disk)

Zero Playwright calls. Sequence: `Read` → `Bash` (`which
playwright` — not found) → 3× `Edit` (the same three defect fixes,
from source inspection) → `Bash` verification substitutes:
`python3 -m http.server` + `curl` greps of the served HTML, a
hand-written Node DOM simulation of the click handler, and a
string-matching check script. Its final tree passes the
independent assertion — the fixes are correct — but it never
inspected rendered state via Playwright, so it does not close
the loop as defined. Its "verification" was self-built
string/DOM-simulation checks, not browser evidence.

### Mechanism (why B could not run the loop)

Arm B's init event lists **4 tools loaded** (Read, Write, Edit,
Bash) — the emitted `ux-ui` frontmatter allowlist, translated by
the adapter from canonical `tools_hint: [read, edit, shell]`
(ledger S21). The Playwright MCP server was configured
identically in both trees (`mcp_servers: playwright, source:
project`) but MCP tool names are not in the allowlist, so no
`mcp__playwright__*` tool was reachable in arm B. Arm A's init
event lists 30 tools; it loaded the Playwright tools via
ToolSearch and used them. This is the risk recorded in the
prereg, realized: **the ux-ui agent as installed is structurally
barred from the browser-verification loop its own canonical
working rules call for** ("Verify rendered output where a
browser/preview is available"). The agent form does not pay off
on this task class; as shipped it routes around the browser.

Descriptive only, no verdict weight: B was cheaper and faster
($0.0425 / 12 turns vs $0.0964 / 18) and its source-level fixes
were identical in effect. A retest with an MCP-capable tools
allowlist on ux-ui would be a different treatment (an adapter /
canonical change), not this claim.

## Harness incident

Arm A's first launch used `--dangerously-skip-permissions`,
which Claude Code refuses under root ("cannot be used with
root/sudo privileges"): exit 1 in 1.5 s, no model turn, $0
metered. Both arms were then run with the identical replacement
flags (`--permission-mode acceptEdits` + `--allowedTools Read
Write Edit Bash Grep Glob mcp__playwright__*`, the X7 pattern).
The failed attempt's tree was discarded; its cost was $0 and it
produced no transcript verdict.
