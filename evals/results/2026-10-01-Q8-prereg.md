## Deliverables

1. `scripts/drift_check.py` — stdlib-only Python, subcommands:
   - `collisions [--home DIR] [--project DIR]` — skill names present at both global scope (`<home>/.agents/skills`, `<home>/.claude/skills`) and project scope (`<project>/.agents/skills`, `<project>/.claude/skills`). Exit 1 naming each collision, 0 when clean. Hazard: install-scopes §1a (Claude global-wins, Copilot project-wins on the same name).
   - `secrets [--root DIR]` — scan tree (skip `.git`, binary files, files > 1 MiB) for `sk-ant-...`, `ghp_`/`gho_`/`github_pat_...`, `AKIA...`, `-----BEGIN ... PRIVATE KEY-----`, and KEY/TOKEN/SECRET assignment lines with high-entropy values. Allowlist: `.drift-allow` at root, one path per line. Exit 1 with `file:line` per finding; matched secrets redacted to a short prefix, never printed in full.
   - `pins [--root DIR]` — (a) every entry in `canonical/skill-pins.json` SHA-256-hashes to its pinned value (logic reused from `scripts/import_skill.py`: same pin path, same hash; missing pins file = no pins recorded = pass, matching `import_skill.py verify`); (b) every MCP package spec in `canonical/mcp/*.json` (and package-shaped tokens in `scripts/adapters.py`) carries an exact version pin — `@latest` or a bare unpinned package name is flagged. Exit 1 naming each mismatch/unpinned spec.
   - `all` — run all three against the repo root + real HOME/project defaults, one-line summary per check, exit 1 if any check fails. Weekly verify entry point.
2. `scripts/verify-weekly.sh` — thin bash wrapper: runs `drift_check.py all`, propagates its exit code.
3. `scripts/test_drift_check.py` — self-test, stdlib only. Builds scratch fixtures under a temp dir under `~/workspace` (creates and cleans up), plants (i) a skill name at both scopes, (ii) a fake secret in a text file, (iii) a tampered copy of a pinned skill; asserts each subcommand exits 1 and names the plant, a clean fixture exits 0, and `all` against the real repo tree exits 0. Prints PASS/FAIL per case, exits nonzero on any failure.
