## Pre-registered protocol (written before any model run)

- Corpus: `wiki/notes/` at ce0edbe — the real-wiki counterpart of the
  seeded fixture (`evals/fixtures/wiki-seed/`, a flat notes dir).
  Session logs under `wiki/sessions/` are not notes (no note status;
  `status:` there is session state) and are excluded, as in the
  original where the corpus was notes only. Index/data-model/log are
  orientation files, not corpus notes, in both runs.
- Exclusion rule, identical to the original: eligible = all notes;
  active-only = notes with `status: active` (archived/stale excluded
  from retrieval; AGENTS.md §3, data-model lifecycle).
- Token counting, identical to the original partial run
  (`2026-09-30-E5-partial.md`): chars/4 estimate over the note files
  in each setting. Recomputed on the seed fixture today this gives
  8,974.5 (all) / 5,571.25 (active) vs the originally reported
  ~8,957 / ~5,565 — 0.2% reporting drift in the original, formula
  unchanged.
- Quality measurement, mirroring the original full run
  (`2026-09-30-E5.md`): cold Claude Haiku
  (`claude-haiku-4-5-20251001`, `--bare`, apiKeyHelper, scratch dir
  per setting), 10 probe questions, instruction in both settings:
  answer from the notes present; say "not recorded" when absent.
  The original 10 probes are not on disk (audit finding,
  `docs/claude-critique-2026-09-30.md`), so the questions are new but
  of the original kind — frontmatter/count/verdict facts, each
  grep-verifiable against the corpus. Answer key fixed here, before
  the runs:

  1. Verdict in note `claude-advisor`? — PROVEN
  2. `verified` date of note `telemetry-storage`? — 2026-09-30
  3. How many notes are in the corpus? — 16
  4. How many notes have `status: archived`? — 0
  5. `type` of note `feedback-loop`? — procedure
  6. Which note does `session-lifecycle` list in `relates_to`? —
     telemetry-storage
  7. Verdict in note `opus-55-prompt-regression`? — UNVERIFIABLE
  8. Evidence file cited by note `session-end-hook`? —
     evals/results/2026-09-30-X5-sessionend-probe.md
  9. How many canonical agents does the roster-of-record correction
     in note `v2-roster` say are on disk? — 12
  10. Does any note carry a `superseded_by` field? — no

- Scoring, identical to the corrected original: against fixed corpus
  truth; "not recorded" for a fact present in the corpus is a wrong
  answer. Pre-registered E5 threshold: PASS iff quality drop ≤ 1
  correct answer AND token cut ≥ 30%.
- Spend cap: $0.50 metered, hard stop. Original two runs cost
  $0.0568 + $0.0343 = $0.0912 at comparable corpus size.
