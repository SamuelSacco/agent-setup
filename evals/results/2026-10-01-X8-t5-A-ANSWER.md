# Receipts Storage Decision

## Decision (with date)

Receipts are stored as an **append-only JSONL file** (one JSON object per line), decided **2026-02-18**.

## Alternative considered and rejected

**SQLite** was considered and rejected because:
- There is a single writer and every consumer reads files directly
- A database earns nothing yet (adds no value in the current context)

## Triggers to revisit this decision

The decision should be revisited if any of these occurs:
- A **second concurrent writer** appears
- The receipts file exceeds **50,000 lines**
- **Cross-machine queries** are needed
