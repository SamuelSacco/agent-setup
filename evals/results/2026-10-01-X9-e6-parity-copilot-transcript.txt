## Contract

**TokenBucket Rate Limiter**

**Purpose:** Control the rate of operations using the token bucket algorithm.

**Interface:**
- `TokenBucket(capacity: float, refill_per_sec: float)`
  - `capacity`: maximum tokens the bucket can hold
  - `refill_per_sec`: tokens added per second (refill rate)

- `allow(tokens: float = 1.0) → bool`
  - Consumes `tokens` from the bucket if available
  - Returns `True` if consumption succeeded, `False` otherwise
  - Tokens refill automatically based on elapsed time since last check

**Semantics:**
- Tokens are a floating-point resource
- The bucket refills at a constant rate up to capacity
- Once consumed, tokens are immediately gone
- Allow checks time since last invocation to calculate refill amount
- Thread-safe (no shared mutable state between concurrent calls by default)
