## 6. V2 roster recommendation

Derivation principle: ECC is a catalog (68 agents / 293 skills), not a setup. A default roster is what earns always-installed status under context rent; everything else is an opt-in pack selected per stack. Default ceiling used here: 7 agents, 8 skills, 4 MCP servers.
